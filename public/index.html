Nightfall Search is an independently branded browser project built around the goal of supporting as many Chromebook models as practical.

Development status: browser builds are not available yet.

Designed for broad Chromebook support

The project is preparing separate build targets for 64-bit Intel/AMD (x86_64) and 64-bit ARM (aarch64) devices. Older hardware may not support current browser requirements.

This website is the project landing page. It does not itself provide browser functionality or install a browser.
